# .github

Organisation-wide defaults for TheBeardedBearSAS: the public profile (`profile/README.md`), and the issue and pull
request templates used by every repository that does not define its own.

`profile/README.md` is generated from the URSSAF packages catalogue: run
`python -I .scaffold/org_profile.py .scaffold/opensource/packages.json <this repo>/profile/README.md` from
`Projects/Urssaf` (through Docker), never edit it by hand.
